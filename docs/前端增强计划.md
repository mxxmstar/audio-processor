# 前端增强计划（Loading / 识别历史 / 子菜单）

> 本文档基于 `开发计划.md` 的已完成阶段，规划下一轮前端增强。
> 当前前端栈已迁移为 **Vue 3 + ant-design-vue 4**（Svelte 版本已废弃），Tauri 2 命令层通过 `invoke` 调用。
> 后端音频识别链路（`recognizer` 模块 + `identify` 命令）已可用，本次在其上叠加历史记录与界面优化。

---

## 目标总览

| 编号 | 目标 | 涉及层 | 优先级 |
|---|---|---|---|
| A | Loading 动画：识别 / 下载过程给出明确加载反馈 | 前端 Vue | 中 |
| B | SQLite 维护识别历史：自动落盘、列表查看、删除 | 后端 Rust + 前端 Vue | 高 |
| C | 音频识别子菜单：左栏「音频识别」下挂「识别」「历史记录」 | 前端 Vue（App.vue 菜单） | 中 |

---

## 阶段 A：Loading 动画

> 目标：让用户清晰感知后台耗时操作（指纹计算 + AcoustID 网络查询通常 1~5s），避免误以为卡死。

### A.1 识别界面 Loading（RecognizerView.vue） ✅ 已完成
- [x] `识别中` 按钮已用 `:loading`，保留。
- [x] 结果区用 `<a-spin :spinning="identifying" tip="正在计算音频指纹并查询 AcoustID…">` 包裹，识别期间显示旋转指示器 + 提示文案。
- [x] 失败/成功后 `a-spin` 停止，结果卡片或告警正常渲染；新增占位提示「选择音频文件并点击开始识别以查看结果」。

### A.2 下载界面 Loading（DownloadView.vue） ✅ 已完成
- [x] 解析按钮 `:loading="resolving"`、下载按钮 `:loading="downloading"` 已具备，保留。
- [x] 登录态检查期间 `<a-spin>` 提示（已有 `checkingLogin` 分支），统一 spinner 风格。
- [x] 二维码弹窗加载期间加 `<a-spin :spinning="!qr" tip="正在生成登录二维码…">` 包裹。

### A.3 全局 Loading 规范 ✅ 已完成
- [x] 统一使用 antd `<a-spin>`，避免混用原生 spinner；长任务（>800ms）必须可见反馈。

**阶段 A 完成标志**：识别与下载全流程均有明确 loading 反馈，无"静默等待"窗口。

### 阶段 A 实施明细

### B.2 后端：Tauri 命令（commands.rs） ✅ 已完成

- [x] `history_dir(app)` 取 `app_config_dir` → `resource_dir` → `CARGO_MANIFEST_DIR/..` 兜底。

### B.3 前端：历史记录视图（HistoryView.vue，新建） ✅ 已完成

- [x] 「查看」用 `<a-drawer>` 展示完整记录（含文件路径、识别时间）。

## 实施顺序建议

```
阶段 A（Loading）── 纯前端，风险低，先做
阶段 B（SQLite）── 后端 rusqlite + 命令 + 前端视图，核心价值
阶段 C（子菜单）── 前端布局，依赖 B 的 HistoryView 已存在
```

- A 与 C 无后端依赖，可并行；B 是前提，建议优先完成 B 的后端部分再补前端。
- 全部完成后统一 `cargo build` + `npm run build` 验证。

## 阶段 D：历史记录模块独立化 + B站下载历史（重构）

> 目标：将历史记录逻辑从 `recognizer/history.rs` 抽离为**独立通用模块** `history`，
> 同时支持「音频识别」与「B站下载」两类历史，避免重复实现。

### D.1 通用历史模块 `src-tauri/src/history.rs`（新建） ✅ 已完成
- [x] 定义 `HistoryKind { Recognize, Download }`（`as_str()` → `"recognize"` / `"download"`；`label()` 中文标签；`from_str` 解析）。
- [x] 定义 `HistoryItem { id, kind, title, subtitle, payload, created_at }`（`payload` 为 JSON 字符串，存各自详情）。
- [x] 单表 `history`：`id, kind TEXT, title TEXT, subtitle TEXT, payload TEXT, created_at TEXT DEFAULT (datetime('now','localtime'))`（建表 SQL 含两索引）。
- [x] CRUD：`open_db(dir)`、`insert(kind, title, subtitle, payload_json)`、`list(kind: Option<&str>, limit)`、`get(id)`、`delete(id)`、`clear(kind: Option<&str>)`。
- [x] DB 文件名统一为 `history.db`（取代旧 `recognize_history.db`）。
- [x] `lib.rs` 声明 `pub mod history;`。

### D.2 改造 recognizer 历史 ✅ 已完成
- [x] 删除 `src-tauri/src/recognizer/history.rs`，`recognizer/mod.rs` 移除 `history` 声明。
- [x] `commands.rs` 的 `identify` 成功后改为 `history::insert(HistoryKind::Recognize, &result.title, &result.artist, &payload)`，payload = `serde_json::to_string(&result)`。
- [x] 删除旧命令 `get_recognize_history` / `get_recognize_record` / `delete_recognize_record` 及 `lib.rs` 注册；新增 `get_history(kind?, limit?)` 与 `delete_history(id)`。

### D.3 B站下载历史 ✅ 已完成
- [x] `commands/bili.rs` 的 `bili_start_download`：在 `run_batch` 完成后，遍历任务，对每条调用 `history::insert(HistoryKind::Download, &t.title, &subtitle, &payload)`（无论成功/失败均记录）。
- [x] `subtitle = format!("{} · {}", mode_label(t.mode), status_label(t.status))`；`payload = serde_json::to_string(t)`；新增 `mode_label()` 函数（DownloadMode → 中文）。
- [x] DB 路径用 `history_dir(&app)` 兜底链（与识别一致）。

### D.4 统一前端历史视图（HistoryView.vue） ✅ 已完成
- [x] 改用统一命令 `get_history(kind?, limit?)` 与 `delete_history(id)`。
- [x] 列表支持按 `kind` 过滤（`<a-segmented>`：全部 / 音频识别 / B站下载），切换即刷新。
- [x] 详情抽屉展示通用字段（类型/标题/副标题/记录时间）+ 原始 `payload` JSON（`pre` 格式化）。
- [x] 删除调用 `delete_history`，`<a-popconfirm>` 二次确认后刷新。
- [x] 空状态 `<a-empty>`、`loading` 的 `<a-spin>` 保持。

### D.5 忽略项 ✅ 已完成
- [x] `.gitignore`：`history.db` 取代 `recognize_history.db`（含 `**/history.db`）。

### 阶段 D 实施明细
